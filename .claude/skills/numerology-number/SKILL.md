# numerology-number — Thai numerology lottery skill

หน้าที่ของ skill นี้คือ **เปลี่ยนหลักเลขศาสตร์ไทย (เลขศาสตร์) ให้เป็นคะแนน 0–100** ที่เครื่องสุ่มเลขใน `lib/lottery.ts` ใช้จัดอันดับชุดเลข 6 หลัก พร้อมเหตุผลภาษาไทยที่อ้างอิงตำราได้

ที่มา: PDF ภายในโปรเจกต์ — `00042_เลขศาสตร์ชื่อนั้นสำคัญไฉน` และ `A_17147` รวมกับธรรมเนียมเลขศาสตร์ไทยที่ทั้งสองแหล่งเห็นตรงกัน

---

## เมื่อไรควรเรียก skill นี้

- ผู้ใช้พูดถึงคำหนึ่งใน: "เลขศาสตร์", "ผลรวมมงคล", "เลขชะตา", "เลขกาลกิณี", "ดาวประจำเลข", "ทักษาปกรณ์"
- ผู้ใช้เลือกศาสตร์ `"numero"` ในหน้าหลัก (`app/page.tsx`)
- ผู้ใช้ขอเหตุผลของชุดเลขที่ระบบสุ่มมาในแง่ของเลขศาสตร์ (เช่น "ทำไมชุดนี้ถึงดี", "ชุดนี้เป็นกาลกิณีไหม")

ถ้าผู้ใช้ไม่ได้พาดพิงเรื่องเลขศาสตร์เลย และไม่ได้เลือก `numero` — **อย่าเรียก skill นี้**

## โครงสร้างไฟล์ที่เกี่ยวข้อง

| ไฟล์ | หน้าที่ |
|------|---------|
| `lib/numerologyData.ts` | ฐานความรู้: ความหมายเลข 1–9, ความหมายเลขคู่ 10–30, AUSPICIOUS_SUMS, เลขกาลกิณีตามวันเกิด, เลขเด่นประจำวัน |

## 5 มิติของคะแนนเลขศาสตร์ (0–100)

```
final = 0.30 × sumScore        // ผลรวม 6 หลัก ตรง AUSPICIOUS_SUMS หรือไม่
      + 0.20 × back2Score      // ความหมายของท้าย 2 ตัว (ตาราง 10–30 + reduce-to-single)
      + 0.25 × personalScore   // เลขชะตา (วันเกิด) / เลขชื่อ ตรงกับผลรวม-ย่อ
      + 0.25 × dayDigitScore   // 6 หลักมีเลขเด่นประจำวันเกิดกี่ตัว
      − kaalakiniPenalty       // เลขกาลกิณี (ตามวันเกิด) ปรากฏกี่ครั้ง × 6
```

**Behavior contract:**
- ถ้าผู้ใช้ไม่กรอกข้อมูลใดๆ → ทุก sub-score กลับไปที่กลาง (~50) → final ใกล้ 50 (ไม่ลำเอียง)
- ถ้ากรอกครบ → ช่วงคะแนนกระจาย 25–95
- กาลกิณีตัดได้สูงสุด 30 คะแนน (เลขกาลกิณีปรากฏ 5+ ตัว)

| เลข | ดาว | โทน | คำสั้นๆ |
|-----|-----|-----|----------|
| 1 | อาทิตย์ | auspicious | ผู้นำ บารมี |
| 2 | จันทร์ | neutral | เสน่ห์ อ่อนหวาน |
| 3 | อังคาร | warn | กล้าหาญ แต่ร้อนแรง |
| 4 | พุธ | neutral | เจรจา การค้า |
| 5 | พฤหัสบดี | auspicious | ผู้ใหญ่หนุน |
| 6 | ศุกร์ | auspicious | ความรัก ศิลปะ |
| 7 | เสาร์ | warn | อุปสรรค อดทน |
| 8 | ราหู | warn | พลิกผัน เงินทางลัด |
| 9 | เกตุ | auspicious | บารมีแรง |

### ผลรวมมงคล (subset ของ AUSPICIOUS_SUMS)
`9, 14, 15, 18, 19, 23, 24, 27, 36, 41, 42, 45, 46, 50, 51, 54, 55, 56, 59, 63, 65, 90, 95, 99, 100`

`อาทิตย์→6, จันทร์→1, อังคาร→2, พุธ→5, พฤหัสบดี→4, ศุกร์→8, เสาร์→3`

## 3-step flow ของ skill

1. **อ่าน user profile**
   - ใช้ `user.birthDate` เพื่อหา (ก) เลขชะตา (ข) เลขกาลกิณี (ค) เลขเด่นประจำวัน
   - ใช้ `user.fullName` ผ่าน `THAI_LETTER_MAP` ใน `numerology.ts` เพื่อหาเลขชื่อ
   - ทั้งสองอย่างเป็น optional — ถ้าไม่มี ให้คะแนนเป็นกลาง

2. **ให้คะแนนชุดเลขที่ generator (GA + random) สร้างขึ้น**
   - เรียก `numerologyScore(num, user)` ใน `scoreNumber` ของ `lib/lottery.ts`
   - ค่าออกมาเป็นองค์ประกอบหนึ่งใน `breakdown.numero` (0–100)
   - สูงกว่า 70 → trigger signal "เลขศาสตร์ตรงดวง"
   - สูงกว่า 60 → มีสิทธิ์ได้ highlight "เด่นด้านเลขศาสตร์"

3. **คืนเหตุผลภาษาไทย**
   - `numerologyExplanation(num, user)` ส่ง bullet สั้นๆ เช่น "ผลรวม 24 เป็นผลรวมมงคล • ท้าย 2 (15) เสน่ห์เด่น โชคดี • มีเลขเด่นประจำวันเกิด 4/6 หลัก"
   - ใช้ใน `fallbackReason` เมื่อ LLM ใช้ไม่ได้ และเป็น grounding hint ในคำสั่ง LLM ของ `/api/analyze`

## ข้อควรระวัง (เคยเจอ)

- **อย่าเปลี่ยนการ reduce-to-single ของผลรวม** — มีผลต่อ life-path number; logic นี้ใช้ร่วมกับ `astrology.ts` และ `lottery.ts`
- **0 ไม่มีดาวประจำ** — `DIGIT_MEANINGS` เริ่มที่ 1; ใน `singleDigitTone(0)` จะคืน `neutral`
- **PDF บางหน้าระบุ ผลรวม "เด่นการเงิน" ต่างจาก "เด่นบารมี"** — รวมอยู่ใน `AUSPICIOUS_SUMS` ด้วยกัน เพราะการ ranking ใช้แค่ binary auspicious/no
- **เลขศาสตร์ ≠ การพยากรณ์** — outputs ของ skill นี้ถูกใช้เป็นน้ำหนักร่วมกับ math/astro/fengshui/gap; ไม่ใช่คำทำนายเดี่ยวๆ

## ตัวอย่าง

ผู้ใช้: เกิดวันพุธ ชื่อ "สมชาย" — ขอชุดเลขแนวเลขศาสตร์

ระบบคำนวณ:
- เลขชะตา: ผลรวมตัวเลขวันเกิด → reduce → เช่น 4
- เลขชื่อ: `THAI_LETTER_MAP[ส]+[ม]+[ช]+[า]+[ย]` → reduce → เช่น 6
- กาลกิณีของวันพุธ = 5
- เลขเด่นวันพุธ = [4, 6, 7, 8, 9]

ชุด `461824`:
- ผลรวม = 25 → ไม่อยู่ใน AUSPICIOUS_SUMS, reduce = 7 (warn) → sumScore ~ 25
- ท้าย 2 = 24 → "การเงินคล่อง ลาภลอย" (auspicious) → back2Score = 85
- reduced 7 ≠ life(4) ≠ name(6) → personal ~ 40
- 4/6 หลักเป็นเลขเด่นวันพุธ (4,6,8,4) → dayDig = 30+40 = 70
- กาลกิณี (5) ปรากฏ 0 ครั้ง → penalty 0
- **final** ≈ 0.30·25 + 0.20·85 + 0.25·40 + 0.25·70 − 0 = 52

คำอธิบายส่งกลับ: "ท้าย 2 (24) การเงินคล่อง ลาภลอย • มีเลขเด่นประจำวันเกิด 4/6 หลัก"
